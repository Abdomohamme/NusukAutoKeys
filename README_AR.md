# Nusuk Auto Keys — نسخة أولية

## البناء السحابي من الهاتف
1. فك ضغط ملف المشروع.
2. أنشئ مستودعًا جديدًا على GitHub باسم `NusukAutoKeys`.
3. ارفع محتويات المجلد (بما فيها المجلد المخفي `.github/workflows`) إلى الفرع `main`.
4. افتح تبويب Actions وشغّل `Build Nusuk Auto Keys APK` إذا لم يبدأ البناء تلقائيًا.
5. بعد نجاح البناء، افتح نتيجة التشغيل وانزل إلى Artifacts ثم حمّل `NusukAutoKeys-debug-apk`.
6. فك ضغط ملف الـ artifact وثبّت `app-debug.apk` على هاتفك.

## ما الذي تفعله النسخة؟
- تجلب أحدث 200 كود من واجهة البيانات المفتوحة للموقع.
- تعرض كودًا واحدًا في كل مرة.
- تفتح رابط الكود الذي يقدمه الموقع إلى نسك.
- تسمح بالانتقال اليدوي للكود التالي.

## حدود النسخة الحالية
هذه نسخة أولية قابلة للبناء كمشروع Android Studio وليست تطبيقًا آليًا بالكامل. لا تقرأ بعد رسالة «مبارك» ولا تدخل الأكواد أو تضغط داخل نسك تلقائيًا. يجب اختبار واجهة التطبيق على الهاتف قبل إضافة أي تحكم آلي. لا تتجاوز CAPTCHA أو حدود الاستخدام.

## سياسة تحديث المصدر
واجهة الموقع تنص على عدم طلب ملف البيانات أكثر من مرة كل 15 دقيقة، وعلى أن الأكواد غير مضمونة الصلاحية داخل نسك.
